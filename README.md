# Project Website

This is a small website created for showcasing our design engineering project at the upcoming tech expo. It includes sections for research, development, prototype details, and contact information.

## Structure

- `index.html`: Main HTML file
- `css/style.css`: Custom styles
- `js/script.js`: JavaScript for interactivity
- `images/`: Folder for images (add your project images here)

## How to View

1. Open `index.html` in a web browser.
2. For a better development experience, install the "Live Server" extension in VS Code and use it to serve the site.

## Customization

- Replace placeholder text in `index.html` with your actual project details.
- Add images to the `images/` folder and reference them in the HTML.
- Modify `css/style.css` for additional styling.
- Update `js/script.js` for more functionality.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5 (for responsive design)
